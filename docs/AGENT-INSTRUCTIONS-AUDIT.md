## Feature boundaries checked

- The Library groups artifacts into projects and navigation folders. Membership/navigation changes preserve canonical file paths and do not authorize edits to related artifacts.
- General HTML bundles allow local HTML/CSS/SVG/JavaScript without design packs. Presentation `interactive_html` keeps a meaningful static fallback and an isolated offline runtime.
- Live host hooks apply to presentations/design requests. Their compact wake signals request tool reads; they contain no comment body and are not user-facing replies. Generic artifact feedback is durable, with no automatic host continuation. Batch comments, attachments and unsent drafts stay private until explicitly released.
- Workspace rules override secondary learned preferences. Retention hashes omit exact guidance only while the caller retains it; source pointers and receipt metadata do not prove file inspection or model retention.
- Visual captures contain actual rendered images and version metadata. Animation and interaction checks remain necessary. Presentation review still covers every full-size slide, charts, reveal/motion states and fresh independent reviewers; physical display/application limitations must be reported.
- Speaker notes remain brief additional context, with human notes preserved. Sources and routine dates belong in context/source panels unless interpretation requires a footnote.
- **Content changes** and **All saves** filter the UI timeline without deleting retained saves. Restore creates a fresh revision. Artifact revisions retain local dependencies; historical slides reuse current shared theme/assets.
- Local **Save workspace** archives include private state and retained revisions. GitHub backup requires explicit opt-in and includes current sources/navigation only. **Restore workspace** targets a new folder and does not switch the active server or restore upload permissions/agent sessions.
- Right-click commands and keyboard movement/deletion operate on unsent element edits. Multiple slide objects use one group-feedback JSON message with original targets/hash and no group `edit_intent`; delete/supported layer changes preview locally, while other arrangements and alignment record requests without a final-layout preview. Pending edits block selection/navigation until sent or cancelled. Cancel restores local originals; dismissing a sent preview never retracts its request. HTML direct editing remains single-object with group comments. Undo/redo does not retract sent feedback or undo canonical agent revisions. Normal concurrency checks and visual review still apply.

The learning skill intentionally covers presentation transcripts and released slide feedback. It does not promise generic artifact learning.
