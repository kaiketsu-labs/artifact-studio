Clear diagnostic logs?

Deletes server and update logs, including their rotated copies. Projects, conversations, version history and backups are kept. New diagnostics continue to be recorded.

The clear action works while the server is running or stopped. It is disabled during an update. Logging resumes as new diagnostics arrive.
