# Diagnostic log controls — layout preview

Serve `index.html` over local HTTP to inspect the Mac menu and confirmation layout in light/dark appearance. Its controls demonstrate cancellation, confirmation and continued diagnostic output with fictional data. They do not access or delete files.

The implemented controls are in `macos/ArtifactStudio.swift`. This browser preview supplies visual documentation when a native desktop is unavailable; it is not evidence of AppKit interaction behavior. Swift storage/pipe executables test real rotation, clear operations and subprocess drainage. The macOS workflow builds and signs the actual controller. Native menu, focus and alert behavior still require a macOS desktop check.
