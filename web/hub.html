Storage and backup

Artifacts and notes save on this device. GitHub backup uploads saved files; it does not pull changes into your working folder.

What travels with a backup?

GitHub receives current artifact files, project briefs, slides, notes, assets and design references. Review chat, approvals, browser drafts and revision history stay on this device. Restore workspace rebuilds the current content and folder structure. For chats, approvals and history, save a local workspace archive.

Reference folders are read-only. Refresh updates the cached GitHub reference, preserving the working folder.
